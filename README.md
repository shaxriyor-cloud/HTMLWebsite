# Project_fullname1_fullname2

Pair project: multi-page website with HTML, one external CSS file and images.

## Structure
```
Project_fullname1_fullname2/
├── README.md
├── html/    index, tags, gallery, about, contact
├── css/     style.css   (shared by every page)
└── images/  logo and gallery pictures
```
Open `html/index.html` in VS Code with the Live Server extension.

## Git workflow (pair)
1. One person creates the repo on GitHub and invites the other.
2. `git clone <repo-url>` both.
3. Each works on a branch: `git checkout -b nav-menu`
4. `git add .` then `git commit -m "Add navigation menu"` then `git push origin nav-menu`
5. Open a Pull Request, review each other, merge to `main`.
