Main HTML tags

Definition, main attributes and an example for each tag we used in this project.

Tag Definition Attributes Example
<!DOCTYPE html> Declares the document as HTML5. none <!DOCTYPE html>
<html> Root element that wraps the whole page. lang <html lang="en">…</html>
<head> Holds information about the page that is not displayed. none <head>…</head>
<meta> Metadata such as character set or viewport. charset, name, content <meta charset="UTF-8">
<title> Page title shown in the browser tab. none <title>My page</title>
<link> Links an external resource, e.g. a CSS file. rel, href <link rel="stylesheet" href="../css/style.css">
<body> Contains everything visible on the page. none <body>…</body>
<header>, <nav>, <main>, <footer> Semantic containers for page regions. none <nav><a href="index.html">Home</a></nav>
<section>, <article> Group related content; article is self-contained. id, class <article><h2>Title</h2></article>
<h1> to <h6> Headings, from most to least important. id, class <h1>Main title</h1>
<p> A paragraph of text. class, id <p>Hello world.</p>
<a> Hyperlink to another page or resource. href, target, title <a href="about.html" target="_blank">About</a>
<img> Embeds an image (empty tag). src, alt, width, height <img src="../images/logo.svg" alt="Logo">
<ul>, <ol>, <li> Unordered list, ordered list and list item. type, start (ol) <ul><li>One</li><li>Two</li></ul>
<div>, <span> Generic block and inline containers for styling. class, id <div class="box"><span>text</span></div>
<strong>, <em> Strong importance (bold) and emphasis (italic). none <strong>Warning</strong> <em>note</em>
<br>, <hr> Line break and thematic horizontal rule. none Line one<br>Line two<hr>
<table>, <tr>, <th>, <td> Table, row, header cell and data cell. colspan, rowspan <table><tr><th>A</th><td>1</td></tr></table>
<form> Collects user input and sends it. action, method <form action="#" method="post">…</form>
<input>, <label>, <textarea>, <button> Form controls and their labels. type, name, id, for, placeholder, required <label for="n">Name</label><input type="text" id="n">
<figure>, <figcaption> An image (or other media) with its caption. none <figure><img src="a.svg" alt=""><figcaption>Caption</figcaption></figure>
